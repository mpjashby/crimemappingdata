# Aggravated assaults in Chicago, 2010 to 2019

Dataset of aggravated assaults recorded by police in Chicago between
2010 and 2019.

## Usage

``` r
chicago_aggravated_assaults
```

## Format

Data frame with 148,636 rows and 5 columns:

- date:

  Date-time at which assault occurred

- loc_cat:

  Type of location

- longitude:

  Longitude

- latitude:

  Latitude

- district:

  Chicago Police Department District

This dataset is also available as a stand-alone file in comma-separated
values (CSV) format at
<https://mpjashby.github.io/crimemappingdata/chicago_aggravated_assaults.csv.gz>
