# Lancashire ward population

Dataset of 2021 resident population of local authority wards in
Lancashire, in mid 2020.

## Usage

``` r
lancashire_ward_pop
```

## Format

A data frame with 285 rows and 3 columns:

- gss_code:

  Government Statistical Service code for each ward

- ward:

  Ward name

- population:

  Resident population

This dataset is also available as a stand-alone file in Excel (.xlsx)
format at
<https://mpjashby.github.io/crimemappingdata/lancashire_ward_pop.xlsx>.

## Source

Office for National Statistics
