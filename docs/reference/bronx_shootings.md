# Shootings in the Bronx in 2019

Dataset of shootings in the Bronx borough of New York City recorded by
the New York City Police Department (NYPD) in 2019.

## Usage

``` r
bronx_shootings
```

## Format

A data frame with 267 rows and five columns:

- incident_key:

  Numeric reference number for each incident

- occur_date:

  Date offence occurred

- murder:

  Whether the shooting was fatal or not (logical)

- longitude:

  Longitude

- latitude:

  Latitude

This dataset is also available as a stand-alone file in CSV format at
<https://mpjashby.github.io/crimemappingdata/bronx_shootings.csv>.
