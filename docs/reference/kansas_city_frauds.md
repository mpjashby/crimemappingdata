# Fraud offences in Kansas City in 2015

Dataset of fraud offences recorded by Kansas City Police on 14 February
2015.

## Usage

``` r
kansas_city_frauds
```

## Format

A data frame with 6 rows and 6 columns:

- uid:

  Numeric reference number for each offence

- offense_code:

  NIBRS offence code

- offense_type:

  NIBRS offence type

- date:

  Date-time when the offence occurred

- longitude:

  Longitude

- latitude:

  Latitude

This dataset is also available as a stand-alone file in CSV format at
<https://mpjashby.github.io/crimemappingdata/kansas_city_frauds.csv>.
