# Stalking in Queensland from 2001 to 2022

Dataset of annual counts of stalking offences in each police division in
Queensland, Australia, from 2001 to 2022.

## Usage

``` r
qld_stalking
```

## Format

A data frame containing 7,304 rows and 3 columns:

- division:

  Name of police visions

- year:

  Year

- stalking:

  Count of recorded stalking offences

This dataset is also available as a stand-alone file in Excel (.xlsx)
format at
<https://mpjashby.github.io/crimemappingdata/qld_stalking.xlsx>.
