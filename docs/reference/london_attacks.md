# Fatal terrorist attacks in London

Dataset of fatal terrorist attacks in London, United Kingdom, from 2010
to 2018.

## Usage

``` r
london_attacks
```

## Format

A data frame containing 8 rows and 4 columns:

- date:

  Attack date

- latitude:

  Latitude

- longitude:

  Longitude

- description:

  Type of attack and number of people killed

A version of this dataset is also available as a stand-alone file at
<https://mpjashby.github.io/crimemappingdata/london_attacks.csv>.
