# Queensland Police Service division boundaries

Dataset of the boundaries of each division of the Queensland Police
Service, 2022.

## Usage

``` r
qld_police_divisions
```

## Format

Simple features (SF) object containing 331 rows and 2 columns:

- division:

  Police division name

- geometry:

  SF polygons of the outline of each division

This dataset is also available as a stand-alone file in geopackage
format at
<https://mpjashby.github.io/crimemappingdata/qld_police_divisions.gpkg>.
