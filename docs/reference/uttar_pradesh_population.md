# Population of districts in Uttar Pradesh

Dataset of resident population of each administrative district in Uttar
Pradesh, India, in 2011.

## Usage

``` r
uttar_pradesh_population
```

## Format

Data frame containing 75 rows and 7 columns:

- code:

  Abbreviation code

- district:

  District name

- headquarters:

  Administrative centre for the district

- division:

  Division in which the district is located

- population:

  Usual residents, 2011

- area:

  Area, square kilometres

- density_km2:

  Population density, people per square kilometre

This dataset is also available as a stand-alone file in CSV format at
<https://mpjashby.github.io/crimemappingdata/uttar_pradesh_population.csv>.
