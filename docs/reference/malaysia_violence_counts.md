# Violent crime counts in Malaysia, 2006 to 2017

Dataset of annual counts of five types of violent crime in each state of
Malaysia for each year from 2006 to 2017.

## Usage

``` r
malaysia_violence_counts
```

## Format

Data frame with 840 rows and 5 columns:

- region:

  Region (East or West Malaysia)

- state:

  State

- year:

  Year

- crime_type:

  Type of violent crime

- count:

  Count of crimes recorded by police

This dataset is also available as a stand-alone file in `.rds` format at
<https://mpjashby.github.io/crimemappingdata/malaysia_violence_counts.rds>.
