# Murders in Uttar Pradesh

Dataset containing counts of murders in each district in the Indian
state of Uttar Pradesh in 2014.

## Usage

``` r
uttar_pradesh_murders
```

## Format

Data frame containing 75 rows and 2 columns:

- district:

  District name

- murder:

  Count of murders

This dataset is also available as a stand-alone file in CSV format at
<https://mpjashby.github.io/crimemappingdata/uttar_pradesh_murders.csv>.
