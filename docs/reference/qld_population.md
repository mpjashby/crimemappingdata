# Population of Queensland Police Service divisions

Dataset of resident population of each Queensland Police Service
division, 2016.

## Usage

``` r
qld_population
```

## Format

Data frame containing 334 rows and 2 columns:

- police_division:

  Police division name

- population:

  Number of usual residents

This dataset is also available as a stand-alone file in gzipped CSV
format at
<https://mpjashby.github.io/crimemappingdata/qld_population.csv.gz>.

## Source

Queensland Government
