# Counts of burglary in Northamptonshire in 2020

Dataset of counts of burglaries (residential and commercial combined) in
each lower-layer super output area in Northamptonshire, England, in
2020.

## Usage

``` r
northants_burglary_counts
```

## Format

A data frame with 409 rows and 3 columns:

- district:

  Local authority district

- lsoa:

  Lower-layer super output area name

- count:

  Number of burglaries

Lower-layer super output areas (LSOAs) are small spatial areas used for
publishing government statistics in the United Kingdom.

This dataset is also available as a stand-alone file in `.rds` format at
<https://mpjashby.github.io/crimemappingdata/northants_burglary_counts.rds>.
